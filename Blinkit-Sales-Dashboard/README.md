# Blinkit Sales Dashboard

Interactive Power BI dashboard analyzing Blinkit's sales performance, outlet performance, product categories, and key business insights.

## Tools Used
- Power BI
- Data Visualization
- Data Analysis

## Dashboard Preview

![Blinkit Dashboard](dashboard.png)

## Key Insights
- Total Sales: $1.20M
- Total Items: 8,523
- Average Sales: $141
- Average Rating: 3.9
- Supermarket Type 1 generated the highest sales.
- Tier 3 outlets generated the highest sales.
